# graphql

A GraphQL server generated with gqlgen (v0.17.68): the standard "todo" schema with an in-memory resolver and the GraphQL Playground.

## What the code does

Module `github.com/wang900115/server`.

- **`graph/schema.graphqls`**: types `Todo { id, text, done, user }` and `User { id, name }`, query `todos`, mutation `createTodo(input: NewTodo!)` where `NewTodo { text, userId }`.
- **`graph/schema.resolvers.go`**: `CreateTodo` builds a todo with ID `T<random int>` (from `math/rand`), user `{id: userId, name: "user " + userId}`, appends it to `Resolver.todos` and returns it. `Todos` returns the slice.
- **`graph/resolver.go`**: `Resolver` holds `todos []*model.Todo` (the only "database").
- **`graph/generated.go`, `graph/model/models_gen.go`**: generated by gqlgen from the schema and `gqlgen.yml`. Do not edit.
- **`server.go`**: serves the Playground at `/` and the API at `/query` on `$PORT` (default `8080`). Transports: OPTIONS, GET, POST. Adds an LRU query cache (1000), introspection, and Automatic Persisted Queries (LRU 100).

## Concepts you can learn

- **Schema-first GraphQL**: write the SDL, let gqlgen generate types and resolver stubs, then fill in only the business logic.
- **Queries vs. mutations**: reads go through `Query`, writes through `Mutation`.
- **Resolver as dependency injection**: shared state (here a slice) lives on the root `Resolver` struct.
- **Server extensions**: query caching, introspection and persisted queries are opt-in handler middleware.

## How to run

```bash
cd graphql
go run .          # or PORT=9000 go run .
```

Open `http://localhost:8080/` and try:

```graphql
mutation { createTodo(input: {text: "buy milk", userId: "1"}) { id text done user { name } } }
query { todos { id text done user { id name } } }
```

After editing the schema, regenerate with `go run github.com/99designs/gqlgen@v0.17.68 generate` (the plain module-local form fails because `go.sum` lacks the CLI's dependencies).

## Notes

- `done` is never set, so it is always `false`; there is no mutation to change it.
- `r.todos` is appended without a lock; concurrent mutations race.
- Data is lost on restart.
